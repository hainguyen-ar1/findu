3. Scalability — Không scale ngang được hiện tại
In-memory state:
├── chat.gateway.ts: socketMeta, roomPresence (dòng 37–39)
├── matchmaking.gateway.ts: positionTimers (dòng 29)
└── moderation.service.ts: spamTracker (dòng 36)
3 Map này sẽ lệch nhau nếu chạy 2+ instance backend → người dùng A connect instance 1, người dùng B connect instance 2 sẽ không thấy nhau.

Cần làm trước khi scale:

Cài @socket.io/redis-adapter — 1 dòng config nhưng ảnh hưởng lớn
Chuyển spamTracker sang Redis (SETEX)
positionTimers cần tập trung hóa hoặc dùng Redis pub/sub
Matchmaking O(N) mỗi 3 giây:


matchmaking.service.ts
Lines 149-180
// Mỗi user trong queue poll 3s → tryAtomicMatch → ZRANGE 0 -1 (toàn bộ queue)
const candidateIds = await this.redis.zrange(QUEUE_ZSET, 0, -1);
Khi có 100 user trong queue = 100 người × mỗi 3s × quét toàn bộ 100 user = 3.300 lần đọc Redis/giây. Ổn ở hiện tại nhưng cần refactor khi scale.

4. Error Handling — REST tốt, WebSocket yếu
REST (tốt): Envelope chuẩn { success, data } / { success: false, code, message } + requestId xuyên suốt.

WebSocket (thiếu nhất quán):

// hiện tại — không có ApiCode, không requestId
client.emit('error', { message: 'Chưa xác thực' });
// nên là
client.emit('error', { code: ApiCode.UNAUTHORIZED, message: '...', requestId: '...' });
Một số catch trong chat.gateway.ts dòng 136–139 nuốt lỗi không emit về client.

5. Code Quality — Điểm cụ thể cần refactor
Duplicate JWT auth 3 gateway:

// Lặp y hệt ở: gateway.gateway.ts, matchmaking.gateway.ts, chat.gateway.ts

const payload = this.jwtService.verify(token, { secret: ... });
(client as any).userId = payload.sub;
→ Nên tách thành WsJwtMiddleware hoặc WsAuthGuard dùng chung.

Guard này không bao giờ được đăng ký vào DI — auth.module.ts dùng ThrottlerGuard mặc định, không phải CustomThrottlerGuard.

process.env trực tiếp thay ConfigService:


auth.controller.ts
Lines 131-131

8. Thứ tự ưu tiên cải thiện
Phải làm trước production:

Rotate Google Secret bị lộ trong .env.example, thay bằng placeholder
Tắt ALLOW_OTP_BYPASS + dùng crypto.randomInt cho OTP
Đổi OAuth callback sang httpOnly cookie thay token trên URL
Thắt WS CORS production giống HTTP CORS
Sync REDIS_HOST/PORT giữa compose và code
Nên làm sớm: 6. WsAuthGuard dùng chung 3 gateway 7. Đăng ký CustomThrottlerGuard hoặc xóa 8. Refresh token store + rotation 9. Test tối thiểu: matchmaking atomic, OTP flow, chat auth 10. Health check endpoint /health
